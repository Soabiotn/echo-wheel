# Echo Wheel

A four-colour memory game. The red, blue, yellow and green disc lights up a pattern; repeat it back. Each round adds one colour.

Play: https://soabiotn.github.io/echo-wheel/

Installable web app (PWA): open the link in Chrome on Android and choose **Add to Home screen**, or click the install icon in the address bar on desktop. Works offline after the first visit.
